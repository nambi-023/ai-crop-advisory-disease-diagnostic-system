# AI-Based Crop Advisory & Disease Diagnostic System

**SIH 2026 Project**

A web-based prototype for crop-health assessment and basic crop-care advisory.

## Features
- Crop selection
- Leaf image upload interface
- Symptom selection
- Prototype disease assessment
- Crop advisory
- Responsive web UI

## Tech Stack
Python, Flask, HTML5, CSS3

## Run
```bash
pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000`.

## Future Development
- Trained computer-vision disease classifier
- Larger verified agricultural dataset
- More crops and diseases
- Regional-language advisory
- Weather and soil-data integration

> This is currently a prototype/demo. Its assessment is rule-based and is not a substitute for professional agricultural diagnosis.
